# AIStudio-API

A brief description of what your CLI tool does and why it’s useful.

## 📥 Installation

### 1. From Source (Recommended)
If you have Go installed on your machine, you can install the binary directly to your `$GOPATH/bin` folder:

```bash
go install github.com/yuriiter/aistudio-api@latest
```
*Make sure your `~/go/bin` directory is in your system's `PATH`.*

---

## 🚀 How to Use

### Basic Command
Run the server by calling the binary name:
```bash
aistudio-api
```

#### You can now log in to your Google account and start using the server. Just set up BASE_URL to http://localhost:8080/v1 and choose some of Gemini models.
